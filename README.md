# Mrs Knox Teaches · QCAA Grade Projector

A browser-only grade projection calculator for the 48 Queensland General senior subjects listed by the QCAA. Enter results for any completed IA and optionally an EA or practice EA. Each result is converted from the school task's raw maximum to its subject weighting, then compared with the 2025 QCAA subject report grade boundaries.

The data and links are in `subjects.js`; update them when new QCAA subject reports are published. Subject weightings currently follow the 2025 subject reports. A projection assumes the student achieves the same percentage on remaining assessments. Final grades and boundaries may differ. Results remain in the visitor's browser and are not submitted to a server.

## Hosting

For GitHub Pages, publish the `main` branch from the repository root. The site uses no build step. The relative `subjects.js` path works at a project URL.

Independent resource by Mrs Knox Teaches; not a QCAA publication.
